### ⚡ Upstream & Open Source Contributions

Selected pull requests to infrastructure, codecs, and distributed systems:

* **[stephenberry/opus-pure (PR #3)](https://github.com/stephenberry/opus-pure/pull/3):** Eliminated hot-path heap allocations on decode/analysis paths via `Cow<'a, [u8]>` and scratch buffers, bounded Ogg packet reassembly to 16 MiB against DoS, and hardened ARM NEON SIMD dispatch.
* **[rmqtt/rmqtt (PR #381)](https://github.com/rmqtt/rmqtt/pull/381):** Reduced Docker build context by 99% (from 11.4 GB down to 119.5 MB) via targeted `.dockerignore` rules, resolved Linux CI dependencies, and fixed compilation warnings in subscription matching logic.
* **[rmqtt/rmqtt (PR #372)](https://github.com/rmqtt/rmqtt/pull/372):** Implemented core `offline_message` event lifecycle support for the WebHook plugin, enabling webhook listeners to process real-time events for offline MQTT clients.
* **[Lidarr/Lidarr (PR #5750)](https://github.com/Lidarr/Lidarr/pull/5750):** Implemented customizable indexer search pattern schemas in C#/.NET for dynamic criteria handling.
